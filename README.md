# Simulation d’un LAN avec DHCP et Routeur

## Aperçu
Ce projet simule un réseau local (LAN) dans Cisco Packet Tracer. Il inclut un routeur configuré comme serveur DHCP, un commutateur, et trois PC recevant des adresses IP dynamiquement. L’objectif est de démontrer mes compétences en configuration réseau.

## Outils utilisés
- Cisco Packet Tracer
- Microsoft Word (rapport)
- Draw.io (schéma, facultatif)

## Instructions
1. Ouvre `PacketTracer/simulation_lan.pkt` dans Cisco Packet Tracer.
2. Vérifie les configurations dans `Rapport/rapport_simulation_lan.pdf`.
3. Teste la connectivité avec des pings (voir captures).
